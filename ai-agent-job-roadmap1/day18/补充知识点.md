一、文件路径与实际验证
排查方法：
    import os
    print("当前工作目录：", os.getcwd())
    print("文件是否存在：", os.path.exists("orders.csv"))
    注意python相对路径通常以程序运行时的工作目录为起点，不一定是Python脚本所在目录。

二、List of Dictionaries
    普通字典：
        order = {
            "order_id": "1001",
            "product": "鼠标",
            "city": "杭州"
        }
    多个字典放进列表：
        orders = [
            {"order_id": "1001", "product": "鼠标", "city": "杭州"},
            {"order_id": "1002", "product": "键盘", "city": "武汉"},
            {"order_id": "1003", "product": "耳机", "city": "成都"}
        ]
    访问代码：
        print(orders[0])             # 第一条订单字典
        print(orders[0]["product"])  # 第一条订单的商品名称
        print(len(orders))           # 订单总数
