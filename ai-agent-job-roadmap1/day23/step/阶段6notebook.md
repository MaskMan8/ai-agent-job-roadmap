CLI整合
预期用户只需要运行一次程序，就能完成：
1. 读取订单文件。
2. 自动检查数据。
3. 分类正常、异常和待确认订单。
4. 统计销售额。
5. 自动生成5类 CSV 文件。
6. 输出执行结果和文件保存位置。


知识点：
    if __name__ == "__main__":
        main()
    作用：程序的启动开关。直接运行运行这个python文件时，执行main()。
    如果其他python文件导入这个文件，不会自动执行main()

    判断 DataFrame 是否读取失败，优先使用 is None，不要使用 if not DataFrame。

    函数的参数的返回值决定了函数之间如何协作
