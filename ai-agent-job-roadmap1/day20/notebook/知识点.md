字典累加与业务分组统计
    累加器、字典做计数器（统计次数、累计每个商品的销售额）
    按字段分组累加（订单列表按商品分组算总额）
    三个关键点：循环、判断、字典
1.单个字典累加：
        # 模板
        累加字典 = {}
        for 元素 in 数据集:
            if 键 in 累加字典:
                累加字典[键] += 增量
            else:
                累加字典[键] = 初始值
2.字典所有value值求和：
    total = sum(字典.values())
    列表存字典，按指定 key 分组累加：
        # 模板
        累加结果 = {}
        for item in 字典列表:
            分组键 = item["分组字段"]
            累加值 = item["待累加字段"]
    
            累加结果[分组键] = 累加结果.get(分组键, 0) + 累加值


字典.get(键，默认值)时是安全取值的方法：键存在就返回对应值，键不存在就会报错。
和直接d[键]的核心区别：
    d["广州"]：键不存在直接报KeyError，程序崩掉
    d.get("广州", 0)：键不存在安静返回默认值，程序继续跑


data.fieldnames:他是csv.DixtReader对象自带的属性，作用是以列表的形式返回csv文件的所有表头字段名。
None:不存在，和空的内容不同，它是连箱子都不存在。
    1.函数没写return返回None
    2.查找/获取不到结果返回None
    3.变量初始化占位
     用来标记还没有找到，还没有赋值的状态
    4.函数可选参数的默认值
