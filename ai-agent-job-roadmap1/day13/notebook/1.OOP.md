object-oriented-programming面向对象编程：像造物者一样去思考，它也是一种代码封装的方法将相关的数据和函数封装到一起。（让外部通过指定的方法操作的做法叫封装）

类就是一个模具，它是一个抽象的概念，而对象是类的具体实例。对象就是类创造出来的成品，每个成品都具有模具的核心特征，又有自己专属的属性和方法。
对象=属性＋方法
在python中，一个对象的静态特征叫做属性，一个对象所能做的事叫做方法。

class Car:
    def __init__(self, brand):
        self.brand = brand

car1 = Car("Toyota")

print(car1.brand)

    line1:这里的 class 是定义类的关键字，Car 是类名.
    line2: __init__ 是初始化方法，通过初始化方法给类创建属性
            self代表正在造的这个实例对象自己，它后面的参数是创建时需要传入的参数
    line3(保存属性)：实例属性self.brand：
    把参数 balance 的值保存到当前对象自己的 balance 属性中。
    每个对象对立拥有互不干扰。给当前这个实例对象（self）加上一个brand的属性
    line4：实例化，创建实例对象：通过类名加括号调用初始化方法传入具体参数brand就能创建出类的实例对象

属性其实就是写在类里面的变量，方法就是类里面的函数。同一个类创建的不同对象不会共享数据。

self？
class可以创造无数个实例，self用来区分当前是哪一个。
他是python自动递进来的标记，指向当前对象
执行car1 = Car("Toyota")调用它self就指向它。python自动把car1这个对象传给__init__的self
有一个关键细节：调用实例方法时，Python 会自动把当前对象传给 self，所以通常不需要我们手动传入它

self.name = name：把右边参数 name 的值，保存到当前对象的 name 属性中。
name = name：只是让局部变量 name 指向它原本的值，并没有给对象添加 name 属性。





方法（method）
方法就是定义在类里面的函数



执行：
account1 = Account(1000)



实际发生的过程是：
1. Python 根据 Account 类创建一个新对象。
2. Python 自动调用 __init__，把新对象传给 self，把 1000 传给 balance。
3. 执行 self.balance = balance，将 1000 保存到对象的属性中。
4. 创建过程完成后，变量 account1 引用这个对象。
