基础知识
1.什么是JSON?
        JSON是一种数据交换的格式,服务器可以用它向python传递信息。
        （服务器常用的数据返回格式）
        JSON 对象被转换成 Python 数据后，可以像字典一样访问字段
2.HTTP是什么？
应用层的协议
核心模型：一问一答（请求-响应模型）
        HTTP是一种通信规则，不仅规定两台计算机如何发送请求、也规定如何响应数据。
        客户端和服务器之间进行通信时使用的协议，不只适用于 Python
3.API（交互入口）
        服务器提供给程序的接口。
        注：URL要用引号包起来，否则python会把它当作代码来处理
4.requests
        python中帮助我们发送HTTP请求的工具库。
5.GET
        主要作用是获取数据

例子：response = requests.get(url)
        使用requests这个python工具库中的工具，通过HTTP这种通信规则向url（提前定义好的api地址）发送一个get请求并将服务器的响应保存到response变量中。
