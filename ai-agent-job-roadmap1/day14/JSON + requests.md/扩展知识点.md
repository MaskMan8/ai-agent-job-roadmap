

网络请求并不总能成功。我们要学习当请求失败时，如何避免程序直接崩溃。
    发送请求时，可以设置等待时间上限，避免程序一直等待服务器响应。例如：
    requests.get(address, timeout=5)
    表示请求最多等待 5 秒左右，超时会引发异常。
    response.raise_for_status()
    作用是检查 HTTP 响应状态。如果服务器返回 404、500 等错误状态码，它会引发异常；如果是 200，就会正常继续执行。


requests.get() 已经成功收到响应，是否意味着 API 请求一定成功？
不一定成功。 服务器返回响应，不代表请求成功。例如，404 表示资源未找到。JSON 解析也可能另外发生错误


今天你需要做的事情
    1.认识json以及相关知识
    2.从api获取数据（调用api，安装requests工具库）
    3.根据数据进行判断
    4.处理请求异常

response.status_code 获取的是 HTTP 响应状态码，
response.raise_for_status()：检查 HTTP 状态码
