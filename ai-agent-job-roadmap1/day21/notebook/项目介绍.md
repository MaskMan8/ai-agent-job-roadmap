二、项目说明
项目名称：基于 Python 的订单数据质量检查与异常分类系统
项目描述：
基于 Python 构建订单数据质量检查系统，使用 CSV 模块实现订单数据读取、必需字段校验、重复订单识别、数量与单价合法性检查。通过集合、字典和列表实现异常订单分类，使用异常处理机制捕获数据转换错误，并记录原始 CSV 行号及具体错误原因。最终利用 DictWriter 将正常订单、异常订单和待业务确认订单分别导出为 CSV 文件，实现订单数据质量检查、异常追溯及分类交付。

核心技术： Python、CSV、DictReader、DictWriter、数据清洗、异常处理、数据质量检查。
