命令	                                     作用
python -m venv .venv	                    创建虚拟环境
.\.venv\Scripts\Activate.ps1                在 PowerShell 中激活虚拟环境
python -m pip install requests	            安装第三方库
python -m pip list	                        查看已安装的包
python -m pip freeze	                    输出包及其版本
python -m pip freeze > requirements.txt	    将依赖清单写入文件
python -m pip install -r requirements.txt	根据文件安装依赖
