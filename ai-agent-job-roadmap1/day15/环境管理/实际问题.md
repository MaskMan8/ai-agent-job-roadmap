安装完库以后查看库的时候为什么会有其他的库？
    主动安装一个库时会一并安装第三方依赖库
如何根据 requirements.txt 安装依赖？
    python -m pip install -r requirements.txt
                          -r指定文件，需要读取安装的包

命令解释
python -m pip freeze > requirements.txt
                     >把命令输出写入文件:意思就是把python -m pip freeze列出的安装包及版本写入到requirements.txt文件

python -c "import requests; print(requests.__version__)"
    输出版本号：能够正常输出版本号，就说明 requests 仍然可以使用。
