1.venv（工具）:给项目建立独立环境
    如果所有项目共用一套Python环境，依赖可能互相影响。虚拟环境相当于给每个项目准备一个独立的工具箱。
        编程中的依赖:程序干活需要借用外部工具、模块。
            有两种形式的依赖：1.第三方的依赖（别人写好的直接拿来用）2.项目内依赖

2.pip（工具）：管理第三方库
    它是Python的常用管理工具，主要用来安装、查看和管理第三方库。
    学会项目自己的虚拟环境中执行这类命令，而不是默认到电脑的全局环
    境。
    命令	作用
python -m pip install requests	  安装 requests
python -m pip list	              查看当前环境已安装的库
python -m pip freeze	          输出已安装库及其版本，常用于生成依赖清单

 

3.requirements.txt：记录项目所需依赖包+版本
    跨环境一键还原项目依赖：方便在另一个环境中让pip安装依赖
  

4.uv（工具）:将环境的创建、依赖安装等功能整合到一个高效的工具中
    

123的关系
    venv：创建独立环境。
    pip：在环境中安装和管理依赖。
    requirements.txt：记录项目需要的依赖。


PATH是什么？
    PATH 是系统用来查找可执行程序的一组目录。当你输入 uv 时，PowerShell 会在这些目录中寻找 uv.exe。如果安装目录不在搜索范围内，就会报错。

关键原则：执行 python -m venv .venv 时，.venv 会创建在当前工作目录下。因此一定要先进入项目目录，在创建虚拟环境。
