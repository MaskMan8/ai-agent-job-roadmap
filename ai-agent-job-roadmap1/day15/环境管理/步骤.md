二、第二阶段pip
    1.安装requests：python -m pip install requests
    2.查看已安装的库：python -m pip list
    3.验证安装：python -c "import requests; print(requests.__version__)"


三、第三阶段：管理项目依赖
    1.利用pip freeze把依赖包写入记录文件
    python -m pip freeze > requirements.txt
                     >把命令输出写入文件:意思就是把python -m pip freeze列出的安装包及版本写入到requirements.txt文件


四、第四阶段：如何根据这个记录文件来重新安装依赖
    1.在正确的目录下执行安装语句
    2，检查结果（通过输出版本号）

五、uv的使用
    pip是python官方自带，只负责装包的工具；uv可以完全替代pip而且快非常多还顺带包揽虚拟环境Python版本管理以来锁定等一大堆功能。
    1.执行安装命令
    2.验证安装
    用uv来管理依赖
    第一步，运行：
        uv pip install -r requirements.txt


    第二步，检查依赖列表：
        uv pip list


    第三步，验证 requests：
        python -c "import requests; print(requests.__version__)"
